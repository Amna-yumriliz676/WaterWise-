# 💧 WaterWise — Water Conservation Tracker

A Streamlit app to help Pakistanis track, save, and conserve water.

## Features
- 📊 Daily water usage tracker
- 🔍 Leak detection (meter-based)
- 🌧️ Rainwater harvesting calculator
- 🏆 Community challenges
- 🏛️ Government schemes info
- 📚 Urdu education content

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
